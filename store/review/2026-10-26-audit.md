## Other reviewed risks

| Area | Evidence and limit |
| --- | --- |
| Store updates and executable downloads | Store capability registration and Settings omit the updater. The AAB-derived APK has no CranposeAppUpdate class. Store packaging checks exclude installer permission/receiver. Skins and projects are data. |
| Mobile MCP | Android, iOS and web compile out the server. Desktop binds to loopback, rejects browser Origin and invalid Host requests, bounds request sizes and timeouts, and stops on Studio close. Network tests pass. |
| Audio storage and provider failure | The prior Galaxy Tab run began folder playback in 4.615 seconds with no audio-cache growth. Original-file access and bounded reads remain. A forward-only provider cannot support every seek or container. The audit did not alter the physical tablet. |
| Formats and metadata | Prepared descriptions list supported codecs and qualify MP4/MKV/WebM by their audio codec. Protected files are excluded. iOS HLS limits are stated. Browser support is qualified. |
| Screenshots | All ten prepared gallery manifests place the actual player first. File hashes and PNG dimensions were checked. Final galleries must reflect the replacement build and changed agent text. |
| Privacy declarations | Apple says Data Not Collected. Google says no required data collected/shared. Microsoft links the policy and declares use of personal information. The code has no developer analytics or account service. Optional folder sync and external agents need the visible disclosures above. |
| Google audience/access/ads | Saved audience is 13-15, 16-17 and 18+. Ads is No. Sign in details is No restricted parts. Ten declarations are actioned; the foreground-service declaration remains overdue. |
| Apple access and account information | No sign-in requirement, review contact present, Music category, 4+ rating, trader declaration present. Accessibility claims are unconfigured. No unsupported accessibility certification was added. |
| Imports | Archive/document/image limits and duplicate-name checks are enforced. Import and portability tests pass. No downloaded executable content was found. |
| Branding and assets | Listing name is Cranamp; supplied skins are Catamp artwork. Font license and legal documents are packaged. A complete rights/provenance legal review was not performed. |
| Runtime coverage | Android background playback was exercised on the API 36 arm64/16 KB emulator. Exact replacement builds have not yet had iOS device, IPv6-only network or Windows UI acceptance runs. |

The data-safety conclusion depends on the actual data path. Google distinguishes
on-device processing from off-device collection, and its user-initiated sharing
exception does not by itself exempt collection. Recheck the final app's sync,
stream and provider behavior before retaining the declarations. See
[Google's data-safety definitions](https://support.google.com/googleplay/android-developer/answer/10787469).
