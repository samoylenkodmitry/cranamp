Cranamp privacy policy

Effective October 3, 2026. Cranamp is an independent music player and skin editor maintained by Dmitrii Samoilenko.

Your music stays under your control

Cranamp does not require an account and does not include advertising, tracking, or developer-operated analytics. We do not operate a server that receives your music library, listening history, skins, or device identifiers.

The app reads the audio files, playlists, skins, projects and folders you choose. It stores settings, playlist entries, file references, selected skins and playback state on your device. Mobile editions and the Mac App Store edition copy imported audio into the app’s local storage so it remains available after the file picker closes. Audio processing and skin editing happen on your device.

Streams and remote playlists

When you open an audio URL or a remote playlist, Cranamp connects to the hosts you choose and to any audio hosts or redirects that playlist references. Those hosts receive your IP address and the requested URL, including any credentials or query parameters you put in it. Their privacy policies apply. Use HTTPS links when available; HTTP links are not encrypted.

Optional folder sync

Sync is off by default. If you enable it and select a folder, Cranamp writes files containing a randomly generated device identifier, device label, platform, track titles and fingerprints, play counts, listening positions and timestamps into that folder. A cloud or network folder provider, and anyone with access to that folder, can receive those files. Cranamp does not send them to a developer-operated sync service. You can turn sync off in Settings and delete the sync files from your chosen folder.

Skin Studio and connected agents

The desktop Skin Studio can expose an MCP service on the same computer at 127.0.0.1:18765. It is off by default. Use Agent connection to start, test or stop it; closing Studio stops it. iOS, Android and web editions do not run this service. While the server runs, local programs can inspect and edit the active skin and open or save files within the app's permissions. Cranamp does not send this content to an AI provider itself. If you connect an agent, that agent may send artwork, project content, paths or tool results to its provider according to its own settings and privacy policy. Connect only clients you trust.

Permissions and updates

File access supports the content you select. Network access supports the streams and playlists you request and the local MCP service. Mobile media controls and background playback use the operating system's media facilities. Store editions receive software updates through their store. Direct-download editions may contact GitHub when you check for an update.

Retention and deletion

Local settings and saved content remain until you remove them or clear the app's data. Uninstalling may leave exported files, shared sync files or operating-system backups; remove those separately. Cranamp has no service account to delete. Your operating system, app store, cloud storage provider and any connected agent manage their own diagnostics, backups and records.

Support and this website

If you contact support, we receive the information you send, such as your email address, message and attachments, and use it to answer your request. Please omit passwords, private music, secret URLs and other sensitive files. GitHub issues are public.

The website at cranamp.dmitrysamoylenko.in is served from the developer's VPS. The server and hosting infrastructure receive connection information such as your IP address, requested page, browser information and request time. Operational logs may record this information for security and troubleshooting. The landing page does not use analytics, advertising scripts or cookies.

The linked web player is hosted by GitHub Pages. When you open it, GitHub processes connection information under its privacy statement. The player may save its settings and content in your browser. Clear the site's stored data in your browser to remove it.
