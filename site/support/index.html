Cranamp · Privacy policy

Cranamp support

Cranamp is a music player in Rust with WSZ skin support and original Catamp skins. Desktop, iOS, Android and web editions include Skin Studio. The desktop editor can connect to agents through MCP.

Play audio

Store editions start with an empty playlist. No account or purchase is needed.

  1. In the top player window, press the eject button to the right of the playback buttons.
  2. Choose an audio file in the system file picker. Playback starts when you select the file. Press Play to resume if you stop it.
  3. To add a folder, open the plus button (ADD) at the bottom-left of the playlist and choose ADD FOLDER.

The menu button (LIST) at the bottom-right of the playlist contains IMPORT M3U for M3U, M3U8 and PLS playlists, and OPEN URL for an audio stream address. Cranamp does not provide a music catalogue.

Open Skin Studio

On Android and iOS, use the tabs below the player: Player, Skin Studio and Settings. Settings is a separate screen for appearance, playback and folder sync.

On desktop:

  1. Press the lower-right corner of the top player window to open Settings.
  2. Choose Open Skin Studio.
  3. Choose Continue editing to edit the current skin, or Open skin or project to select a WSZ, ZIP or CSTUDIO file.

Canvas contains the drawing tools. Skin contains playlist and visualizer colours, bitmap fonts, window cutouts and cursor artwork. Save and share exports a layered CSTUDIO project or a WSZ skin. Open the exported WSZ in the player to use it.

Files and playback limits

From version 0.1.91, selected audio stays in its original location. Keep the file and its storage provider available. If a moved file or a disconnected provider stops playback, select the file again. A provider that only supplies a forward stream cannot support seeking or containers that need random access.

Native editions support MP3, FLAC, WAV, AIFF, AAC-LC, ALAC, Ogg Vorbis and Opus. MP4, MKV and WebM require a supported audio codec. Protected files are unsupported. Browser playback depends on the browser. On iOS, HLS playback does not support the equalizer, balance or visualizer. See the audio format details.

Connect a desktop agent

In Studio, open Agent connection from the top toolbar, or from Project actions in a narrow window. Start server enables access from programs on the same computer. Copy server URL includes a secret for the current session. Paste that URL into your trusted agent's MCP settings and use Test connection. Each restart requires a new URL. Stop server or close Studio to end access. This feature is unavailable on Android, iOS and the web.

Connected programs can read or change the active skin and use files within Cranamp's permissions. An agent may send artwork, paths or tool results to its own provider. Check the agent's privacy settings before connecting. See the privacy policy.

Report a problem

Email trdmitriisamoilenko@gmail.com or open a GitHub issue. Include the Cranamp version, device and operating-system version, what happened and steps to reproduce it. Remove personal data from screenshots and logs. GitHub issues are public.
