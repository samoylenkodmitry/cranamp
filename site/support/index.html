Cranamp support

Cranamp is a music player in Rust with WSZ skin support and original Catamp skins. Desktop and Android editions include Skin Studio. The desktop editor can connect to agents through MCP.

Get started

  • Open your own audio files or a playlist using the player's file controls. Store editions start with an empty playlist.
  • Open Settings to choose a bundled skin or import a WSZ skin you have permission to use.
  • Use the equalizer, shuffle and repeat controls to adjust playback.
  • To play a stream, add its audio URL. Cranamp does not include a subscription music catalog.

Report a problem

Email trdmitriisamoilenko@gmail.com or open a GitHub issue. Include the Cranamp version, device and operating-system version, what happened and steps to reproduce it. Remove personal data from screenshots and logs. GitHub issues are public.
