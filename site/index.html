FILES AND STREAMS

Play from the original file.

Open audio files or add a folder. Cranamp keeps audio in its original location. You can also open stream URLs and import M3U, M3U8 or PLS playlists.

Audio formats and limits

CLASSIC CONTROLS

Keep your player familiar.

Use the ten-band equalizer and preamp. Pick a bundled Catamp skin or open a WSZ skin. The player remembers your playlist and sound settings.

Playback help

BUILT-IN SKIN STUDIO

Edit the whole skin.

Draw across the joined player windows with layers and masks. Keep a layered CSTUDIO project, or export a classic WSZ skin.

Open Settings in the player, then choose Open Skin Studio.

LAYOUTS FOLLOW THE WINDOW WIDTH

Room for the current tool.

Compact screens keep drawing controls near the canvas. Wider screens show skin parts and tool properties alongside it.

SKIN SETTINGS

Set the exact colour.

Enter HEX or RGB values. Change playlist and visualizer colours with a preview. Skin settings also include bitmap fonts, window shapes and cursors.

DESKTOP ONLY / MCP

Connect your agent.

Enable a local MCP server in Studio to let an agent use the same canvas and drawing history. The server is off by default and stops when Studio closes.

Connected programs can read or change the skin and access files within Cranamp’s permissions. The agent’s provider may receive data that it reads.

MCP is unavailable on Android, iOS and the web.
